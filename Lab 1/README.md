## Baseline Consistency

The independent AI critique uses the final SRS version 1.0 and `Use-Case-Diagram.drawio.png`. If either input changes, increment the requirements version and repeat the critique so the submitted prompt, response, and reviewed artifacts remain consistent.

## Before Submission

1. Replace the outstanding team identity row in `Contributions.md` with every member's name and exact work allocation.
2. Have every team member review and approve the requirements, diagram, mockups, critique selection, and contribution statement.
3. Confirm whether the course portal requires the literal folder name `lab1`. This directory is named `Lab 1` as requested; rename it only if the submission checker is case- or space-sensitive.
4. Submit the primary files listed above together with the editable sources requested by the teaching team.

## Reproducible Sources

The `source/` directory contains the document-generation scripts. It is supporting material rather than a required submission artifact.
